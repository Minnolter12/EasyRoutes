## EasyRoutes
This is a map project based on A* Algorithm, based on Amrita Vishwa Vidyapeetham, Coimbatore.
The algorithm can be used to predict the most efficient path to a goal node, from the start node, using lowest cost calculated by the algorithm.

### Usage

- **Interactive Web Map**: Open `index.html` in any browser or run:
  ```bash
  python3 -m http.server 8000
  ```
- **CLI**:
  ```bash
  python3 easyroutes.py --start E --goal J
  ```
